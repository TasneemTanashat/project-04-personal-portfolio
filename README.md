# Personal Portfolio Website

## 📌 About the Project

This project is a personal portfolio website built as the final capstone project of the Discovery Web Piscine.

The website introduces me, showcases my skills and projects, and provides a way to contact me. It was built from scratch using HTML5, CSS3, and JavaScript without using any frameworks or templates.

## ✨ Features

- **Header & Navigation:** Navigate between the different sections of the website.
- **About Me:** A short introduction with a personal photo.
- **Skills:** A grid displaying my technical skills.
- **Projects:** A showcase of my work from Projects 00, 01, 02, and 03.
- **Hobbies:** A section about my personal interests.
- **Contact Form:** A form for composing a message.
- **Theme Switcher:** Switch between light and dark themes.
- **Responsive Design:** A layout that adapts to different screen sizes.
- **Mobile Navigation:** A responsive navigation menu for smaller screens.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Git & GitHub

## 🚀 How to Run

1. Clone or download this repository.
2. Open the `ex00` folder.
3. Open `index.html` in your web browser.
4. Explore the different sections and try the theme switcher and navigation menu.
